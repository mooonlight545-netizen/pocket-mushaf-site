# Pocket Mushaf — site

Public landing page + browser-based (Web Serial) firmware flasher for the
Pocket Mushaf device. Served from GitHub Pages.

- `index.html` — landing page
- `flash.html` + `manifest.json` + `firmware/` — ESP Web Tools flasher;
  the firmware binaries here are published automatically from tagged
  releases of the (private) code repository
- `assets/` — renders produced by the real renderer

The code repository is private; this repo carries only public material.
Qur'an data and QPC fonts by the King Fahd Glorious Qur'an Printing
Complex via Tarteel QUL. Rendering by FreeType.
